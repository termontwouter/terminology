
# Terminology: digital identity

This repository provides operational definitions and models of **identity**, and related concepts, in order to facilitate and coordinate their use in technical standards and legal regulations.


## Rendering

Make sure the following tools are on the `PATH`:

- [Quarto](https://quarto.org/) (`quarto-cli`)
- [TinyTeX](https://yihui.org/tinytex/) (`tinytex`)

Then run:

`quarto render`
